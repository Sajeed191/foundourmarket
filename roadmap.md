# Security audit roadmap

- [x] Inventory authentication, privileged operations, APIs, storage, payments, uploads, redirects, secrets, and dependencies
- [x] Inspect database grants, policies, functions, and public response surfaces
- [x] Run automated security and dependency scans
- [x] Prepare an evidence-based hardening plan
- [x] Fix only verified vulnerabilities without changing product behavior or presentation
- [x] Run non-destructive adversarial and regression verification
- [x] Produce the production security report and list external manual actions
