# Security audit roadmap

- [ ] Inventory authentication, privileged operations, APIs, storage, payments, uploads, redirects, secrets, and dependencies
- [ ] Inspect database grants, policies, functions, and public response surfaces
- [ ] Run automated security and dependency scans
- [ ] Prepare an evidence-based hardening plan
- [ ] Fix only verified vulnerabilities without changing product behavior or presentation
- [ ] Run non-destructive adversarial and regression verification
- [ ] Produce the production security report and list external manual actions
